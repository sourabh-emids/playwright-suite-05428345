# Generated Playwright test suite

This repository was generated by the Automation Architect from your uploaded
requirements. It is a complete, runnable pytest-bdd + Playwright project --
nothing here depends on the platform that generated it.

## What's in here

- `tests/features/` -- one Gherkin `.feature` file per requirement.
- `tests/steps/` -- the step definitions that implement each feature's steps.
- `pages/` -- page objects: one class per page of the application, holding
  its locators. Step definitions interact with the page only through these.
- `manifest.json` -- which requirement produced which feature file, for
  traceability.

## Running it

Requires [uv](https://docs.astral.sh/uv/) -- no separate virtualenv/pip step.

```bash
uv sync
uv run playwright install --with-deps chromium
cp .env.example .env   # then fill in BASE_URL and, if needed, TEST_USERNAME/TEST_PASSWORD
make test
```

`make test` runs the full suite in parallel and writes an HTML report to
`reports/report.html` and a JUnit XML report to `reports/junit.xml`. Run
`make test-headed` to watch a single-worker run in a visible browser window,
useful while debugging a failing scenario.

On failure, a trace, a screenshot, and a video are written under
`reports/artifacts/`. Open a trace with:

```bash
playwright show-trace reports/artifacts/<test-name>/trace.zip
```

## Re-running after requirements change

This suite is a one-time export, not a live sync. If your requirements
change, regenerate the suite from the Automation Architect rather than
hand-editing `tests/features/` and `tests/steps/` -- `pages/` and everything
outside `tests/` is yours to extend.
